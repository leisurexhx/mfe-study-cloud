# Contributing

Thank you for helping improve MFE Study Cloud.

1. Do not submit real course materials, credentials, personal notes, or production logs.
2. Open an issue for changes that alter the schema, provider contract, security boundary, or UX.
3. Add an Alembic migration for every database change.
4. Use `FakeAnalysisProvider` in all tests. Live API tests are never part of the normal suite.
5. Run pytest, Ruff, and mypy before submitting a change.
6. Add tests for tenant isolation, authorization, uploads, and paid provider paths when relevant.

By contributing, you agree that your contribution is licensed under AGPL-3.0-only.
